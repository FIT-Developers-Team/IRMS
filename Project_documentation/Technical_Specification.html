SOH Sheet — Special Row Structure

!
Critical constraint: Row 2 of the SOH sheet contains ARRAYFORMULA expressions that auto-calculate Qty On SO, Count SO, Qty On LDP, Stock Age, and Action Suggestion for every data row below it. New SOH records are always appended at lastDataRow + 1 and never inserted using insertRowAfter() to preserve these formulas.

API — Google Apps Script Endpoints

All write operations POST JSON to the GAS Web App URL. The body is sent as text/plain with mode: 'no-cors'. The action field in the JSON body routes to the correct GAS handler function.

// Request format (all operations):
fetch(webAppUrl, {
  method: 'POST',
  mode: 'no-cors',
  headers: { 'Content-Type': 'text/plain' },
  body: JSON.stringify({ action: 'ACTION_NAME', ...payload })
});

Background Sync Delay

After every GAS write, a setTimeout(..., 2500) re-fetches the relevant sheet to confirm the write and refresh the local cache. This 2.5-second delay accounts for GAS execution latency before the data appears in the CSV export endpoint.

Business Logic & Key Formulas

ID Generation

// All IDs use the same generator:
generate6DigitId() {
  return Math.floor(100000 + Math.random() * 900000).toString();
}

// Applied per entity:
ticketId  = 'RC-' + generate6DigitId()   // Pickup Request
ticketId  = 'LF-' + generate6DigitId()   // Lost & Found
pickingId = 'PK-' + generate6DigitId()   // Picking Task
putawayId = 'PT-' + generate6DigitId()   // Putaway
movementId = 'SM' + generate6DigitId()   // Stock Movement
activityId = 'SA' + generate6DigitId()   // Stock Activity

Session Expiry Formula

// Session duration: 4 hours (configurable)
const DURATION_MS = 4 * 60 * 60 * 1000;

sessionData = {
  user: user,
  loggedInAt: Date.now(),
  expiresAt:  Date.now() + DURATION_MS
};

// Expiry check (runs every 15 seconds):
isExpired = Date.now() > sessionData.expiresAt

Putaway Completion Formula

// A picking task is complete when total put away >= task quantity:
sumPutSoFar  = SUM(putawayRecords WHERE pickingId == task.pickingId).qtyPut
isCompleted  = (sumPutSoFar + qtyPutThisTime) >= task.qty

// Remaining quantity shown in UI:
remainingQty = Math.max(0, task.qty - sumPutSoFar)

SOH Update Logic — Putaway

// On createPutaway (GAS side):
existingRow = SOH.find(skuCode == sku AND rackLocation == location)

IF existingRow:
  existingRow.qtySoh += qtyPut
  existingRow.updatedAt = NOW()
ELSE:
  SOH.appendRow([sku, location, qtyPut, NOW()])
  // NOTE: Always append at lastDataRow+1, NEVER use insertRowAfter()
  //       to preserve row 2 ARRAYFORMULA calculations.

SOH Update Logic — Stock Movement Completion

// completeStockMovement() — applied locally AND sent to GAS:

// 1. Deduct from source:
source = SOH.find(skuCode == sku AND rackLocation == fromLoc)
source.qtySoh = Math.max(0, source.qtySoh - moveQty)

// 2. Add to destination (Transfer only):
IF type == 'Transfer location' AND toLoc != 'Deduction':
  dest = SOH.find(skuCode == sku AND rackLocation == toLoc)
  IF dest:    dest.qtySoh += moveQty
  ELSE:       SOH.push({ skuCode, rackLocation: toLoc, qtySoh: moveQty })

Role Elevation Check

// Elevated roles see ALL records; others see only their own:
ELEVATED_ROLES = ['super', 'admin', 'manager', 'supervisor', 'spv']

isElevatedRole(user) {
  return ELEVATED_ROLES.includes(user.role.toLowerCase().trim())
}

Data Expiry TTL

DATA_EXPIRY_DURATION_MS = 1 * 60 * 1000  // 1 minute TTL

isExpired = (Date.now() - lastSyncTime) >= DATA_EXPIRY_DURATION_MS

// Background auto-refresh: runs every 60 seconds via setInterval
// Checks current active tab and refreshes only that section's data.
