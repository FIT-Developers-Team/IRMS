Getting Started & Login

Overview

Before performing tasks in IRMS, you must authenticate using your assigned staff credentials. Your user role determines which features and buttons appear in the navigation bar.

Super (Admin)
  • Full system navigation access
  • Can create/edit users, zones, racks, checker lines
  • Can view and manage all staff records
Staff / Checker
  • Create new Pickup Requests
  • Log Lost & Found entries
  • View own requested tickets
Picker
  • View Waiting List & claim tasks
  • Perform rack putaway
  • Execute stock transfers & deductions

How to Log In

  • 1
    Open the application URL
    Open the IRMS application in your browser. If you previously logged in on the same device and your session is active, the dashboard loads automatically.
  • 2
    Enter Username and Password
    Type your registered staff username and password into the login form. Verification occurs instantly on your device.
  • 3
    Select shift and access Dashboard
    Upon successful login, your 4-hour active shift session begins. The application syncs reference data (products, racks, zones) in the background.
Session Note
Your login session remains active for 4 hours. If inactive or expired, a secure lock modal prompts for your password to resume work without losing pending entries.

Creating a Pickup Request

Overview

Checkers or staff members create a Pickup Request when items accumulated at checker lines need to be picked up by warehouse pickers and put into rack inventory.

How to Submit a Request

  • 1
    Navigate to "Pickup Request" and click "+ New Pickup Request"
    Click the primary action button. A request form opens, and a unique tracking ID (e.g. RC-482917) is automatically generated.
  • 2
    Select SKU Code
    Select or type the product SKU code. The system automatically populates the Product Name, Category, and Type (Food / Non-Food).
  • 3
    Choose Checker Line and enter Quantity
    Select the Checker Line location where the items are physically sitting. Input the exact number of units and optional notes.
  • 4
    Click "Submit Request"
    The request immediately appears in your request table with status Pending. It is simultaneously synced to Google Sheets and added to the Picking Task waiting list.
Tip
You can search your submitted requests by Ticket ID, SKU, or Product Name using the search filter bar at the top of the Pickup Request table.

Claiming & Starting Picking Tasks

Overview

Pickers inspect open pending requests in the Picking Task module, select items to collect from checker lines, and swipe to confirm task ownership.

How to Start Picking

  • 1
    Open "Picking Task" and view "Waiting List"
    The Waiting List tab displays all pending pickup requests and lost & found items waiting for physical collection.
  • 2
    Select items to pick
    Checkbox desired items on desktop or tap task cards on mobile. A floating bottom action bar shows the count of selected items.
  • 3
    Tap "Start Picking"
    A swipe confirmation modal appears listing all selected items for final review.
  • 4
    Swipe slider right to confirm
    Drag the interactive slider past 90% to confirm. Unique Picking IDs (e.g. PK-391042) are generated, assigning tasks to your account in status Picking.
Safety Feature
The swipe gesture prevents accidental task claims. Once confirmed, claimed items move to your personal "In Progress" tab.

Putting Away Items into Racks (Putaway)

Overview

Once picked items are transported to warehouse racking, the picker executes a Putaway to place items in a specific rack location and update Stock on Hand (SOH).

How to Complete a Putaway

  • 1
    Open "Picking Task" -> "In Progress" tab
    Locate your active picking task and click the "Complete / Putaway" action button.
  • 2
    Select destination Zone and Rack location
    Use the location picker to search and select the exact rack identifier (e.g. Zone A, Rack A-01-02).
  • 3
    Confirm putaway quantity
    Verify quantity being stored. If full quantity is put away, the task marks Completed. For partial quantities, remaining units stay in progress.
  • 4
    Click "Submit Putaway"
    The system logs a Putaway record (PT-XXXXXX), creates a Stock Activity movement log, and immediately increases SOH for that product at the chosen rack.

Moving Stock Between Rack Locations

Overview

When stock needs to be relocated from one rack to another, a Stock Transfer task is processed through a mandatory 2-step verification procedure to eliminate scanning errors.

Step-by-Step Transfer Procedure

  • 1
    Open "Stock Movement" and click "Complete Task"
    Select an assigned movement task from the task queue. The verification dialog opens.
  • 2
    Step 1: Scan or Type SKU Code
    Scan barcode or manually enter the item SKU code. The system checks exact code equality. If unmatched, execution stops.
  • 3
    Step 2: Confirm Destination Rack
    Confirm destination rack location where physical items are deposited.
  • 4
    Click "Verify & Complete"
    The app decreases SOH at origin rack, increases SOH at target rack, logs dual stock activity entries (Outbound and Inbound), and updates status to Done.
Double-Verification Transfer Procedure

    A["Select Stock Movement Task"] --> B["Click Complete Task"]

    F --> G["Click Verify & Complete"]
    G --> H["Decrease SOH at Origin Rack"]
    H --> I["Increase SOH at Target Rack"]
    I --> J["Log Outbound & Inbound Activity Records"]

Deducting Damaged or Lost Stock

Overview

If items in rack inventory are damaged, expired, missing, or require inventory audit adjustment, staff must submit a Stock Deduction request.

How to Deduct Stock

  • 1
    Locate item in Stock on Hand (SOH)
    Open the SOH module, find the affected product-rack record, and click "Deduct Stock".
  • 2
    Select Reason and enter Quantity
    Choose reason: Bad/Damaged/Expired, Lost/Missing, Discrepancy Correction, or Sample/Testing. Target destination is locked to Deduction.
  • 3
    Submit Deduction Request
    A Stock Movement task of type Deduction is enqueued. Stock is NOT subtracted until double verification is completed in Stock Movement.
  • 4
    Complete verification in Stock Movement
    The assigned staff verifies SKU scanning in Stock Movement module to permanently decrement SOH.
Stock Deduction Flow 
flowchart TD
    A["Find Item in SOH List"] --> B["Click Deduct Stock"]
    B --> C["Select Reason & Qty"]
    C --> D["Submit Deduction Request"]
    D --> E["Enqueue Stock Movement (Type: Deduction)"]
    E --> F["Perform SKU Scan Verification in Movement"]
    F --> G["Permanently Decrement SOH & Log Deduction Activity"]

Recording Found Items (Lost & Found)

Overview

Unplaced or stray items discovered anywhere in the warehouse are registered via Lost & Found so pickers can retrieve them and store them in permanent rack inventory.

How to Log Found Items

  • 1
    Navigate to "Lost & Found" and click "+ New Entry"
    A ticket identifier (e.g. LF-728341) is automatically generated.
  • 2
    Enter Product SKU, Quantity, and Temporary Location
    Input product SKU code, quantity found, and physical zone/area where item was discovered.
  • 3
    Submit Lost & Found Entry
    Entry saves with status Pending and automatically routes into the Picking Task Waiting List for putaway processing.

Monitoring Stock on Hand (SOH)

Overview

The Stock on Hand (SOH) screen provides live visibility into total warehouse inventory breakdown by product SKU, category, zone, rack location, and aging metric.

Key Features & Filtering

FeatureDescriptionUse Case
Summary KPI Cards Displays Total Unique SKUs, Total Item Units, High-Age items, and Deduction counts. Quick operational audit dashboard view.
Search Bar Filter by product SKU, product name, or rack code. Locating specific stock locations instantly.
High-Age Stock Filter Highlight items stored longer than standard retention threshold. Stock rotation and inventory auditing.

Master Data Management (Admin)

Overview

Users with the Super (Admin) role manage system master data using the Admin Panel. Changes sync directly to reference sheets and update pickers' forms instantly.

Admin Configuration Options

ModuleConfigurable DataImpact
User Management Add staff accounts, edit roles (Super/Staff/Picker), update passwords. Controls authentication and feature permission access.
Zone Management Create, rename, or delete warehouse zone codes. Updates zone choices across putaway and location pickers.
Rack Management Add rack codes with zone, aisle, bay, level, and capacity attributes. Defines valid location targets for putaway and transfers.
Checker Lines Configure active checker line identifiers. Updates available origin lines in pickup request forms.

Data Syncing & Troubleshooting

Data Syncing Mechanism

IRMS operates on an offline-first architecture. All records are saved instantly to local browser database (IndexedDB) and synchronized with Google Sheets in the background.

Sync Toolbar Controls

  • Sync Button (Header Bar) — Triggers a manual background refresh of active tab data from Google Sheets.
  • Flush Cache & Full Resync — Clears local browser cache and re-downloads all product catalogs, racks, zones, and task lists from cloud storage.

Troubleshooting Common Issues

IssueProbable CauseResolution Action
SKU Scan Mismatch Error Scanned barcode does not match task target SKU. Verify physical item barcode against task ticket SKU code.
Session Expired Lock Screen 4-hour shift duration elapsed. Enter password in lock modal to unlock session. Unsaved draft data remains intact.
Data Not Appearing for Teammates Internet connection temporarily disconnected. App will auto-sync once connection restores. Click manual Sync button when back online.
